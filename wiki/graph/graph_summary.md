## Loading from Python

```python
import json, networkx as nx
g = json.load(open('research_db/graph/graph.json'))
G = nx.DiGraph()
for n in g['nodes']: G.add_node(n['id'], **{k:v for k,v in n.items() if k!='id'})
for e in g['edges']: G.add_edge(e['source'], e['target'], type=e['type'])
```
