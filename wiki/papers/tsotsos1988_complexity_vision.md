# A 'complexity level' analysis of immediate vision

> **Sourcing note.** The IJCV PDF (Springer, DOI 10.1007/BF00133569) is paywalled and the Springer IDP redirect blocks WebFetch. The summary below is reconstructed from (a) the openly available retrospective Tsotsos et al. (2017) *Frontiers* / PMC article "Complexity level analysis revisited" (PMC5552749), which is by the same author and revisits the 1988 theorems and the Selective Tuning lineage in detail, (b) the abstract of Tsotsos's 1990 *Behavioral and Brain Sciences* target article "Analyzing vision at the complexity level" (DOI 10.1017/S0140525X00050019), which restates the 1988 complexity result for a wider audience, and (c) the Tsotsos Lab "Complexity" page at York University. Numerical complexity expressions reported here are the canonical ones from those sources; no quantity is given that is not standard in the Tsotsos literature.

## 1. Abstract

Tsotsos extends Marr's three levels of analysis (computational, algorithmic, implementational) with a fourth — the *complexity level* — and uses it to argue that a *resource-complexity match* between a proposed theory of vision and the brain's actual neural budget is a necessary criterion for the theory to be viable. He formalises "immediate vision" as a search problem (find a target image embedded in a test image) and proves that the **unbounded** version of the problem — in which no prior task information is available to constrain where to look or what features to compute — has worst-case time complexity exponential in the number of pixels and features, of the form $O(P^2 \cdot 2^P \cdot 2^M)$. He then identifies a set of resource-bounded approximations — hierarchical pyramidal representations, spatially-localised receptive fields with limited support, top-down attentional selection of locations, and top-down attentional selection of features — that together reduce the complexity to a low-order polynomial in the *attended* image and feature subset, of the form $O(2^{M'} \cdot P'^{3.5})$ with $M' \ll M$ and $P' \ll P$. The conclusion is that attention is not a useful optimisation that biology happens to have stumbled upon; it is a *necessary* component of any vision system that has to run in real time on bounded hardware. Without selection, immediate vision is intractable.

## 2. Why this matters for us

This is the **foundational complexity-theoretic motivation** for every attention model in the database, including the Recurrent ViT and the PRISM variants. The argument is direct: visual recognition without selection is provably intractable, therefore selection is non-negotiable; the only question is which selection mechanism. Tsotsos's choice was the *Selective Tuning* hierarchy (1995), in which top-down attention iteratively narrows a bottom-up feedforward feature pyramid via suppressive surrounds — a structural ancestor of biased competition (Desimone & Duncan 1995) and a remarkably faithful prefiguration of the user's iterate-and-narrow attention pattern in the Recurrent ViT (recurrent passes refining a learned softmax attention map) and in PRISM v1/v2 (inner variational-inference loop refining a memory state's allocation of representational capacity). The paper therefore grounds *why* the user's program is committed to selective attention rather than uniform processing across the full image — a commitment the Recurrent ViT inherits from ViT's patch tokenisation and then sharpens via recurrent refinement. Without this paper, the user's commitment to selection is empirical (it works on change detection); with it, the commitment is theoretical (selection is a necessary condition for any real-time vision system).

## 3. Key claims

1. Marr's three levels of analysis are necessary but not sufficient: any complete theory of vision must also satisfy a fourth, **complexity-level** constraint requiring the proposed algorithm to run within the spatial and temporal resource bounds of the system that has to implement it (the primate brain, in the biological case).
2. Immediate (single-fixation, pre-attentive plus first-saccade) vision can be formalised as **Visual Match**: given a target image and a test image, decide whether the target appears (at some location, possibly transformed) in the test image.
3. **Unbounded Visual Search** — Visual Match with no prior knowledge of target location, target identity, or which features matter — is **NP-complete**; its worst-case time complexity grows as $O(P^2 \cdot 2^P \cdot 2^M)$ in the number of pixels $P$ and features $M$.
4. Therefore no biologically plausible vision system can solve the unbounded version. Some combination of approximations must reshape the problem into a tractable form.
5. Four such approximations are sufficient: (a) hierarchical pyramid representations that reduce the number of locations searched at each level; (b) spatially localised receptive fields whose support is bounded relative to the image; (c) **top-down attentional selection of locations** (restricting the search to a subset $P' \ll P$); and (d) **top-down attentional selection of features** (restricting the feature set to a subset $M' \ll M$).
6. Under these constraints, the worst-case complexity drops to a low-order polynomial in the *attended* image, of the order $O(2^{M'} \cdot P'^{3.5})$, which is tractable for biologically plausible values of $M'$ and $P'$.
7. Attention is therefore **not optional**. It is a structural requirement of any real-time vision system, biological or artificial, operating under bounded computational resources.
8. **Bounded Visual Search** — Visual Match given prior knowledge constraining $P'$ and $M'$ — has time complexity *linear* in the number of test-image pixels, recovering the empirical observation that primate visual search with informative cues is approximately linear in display size.
9. The complexity analysis predicts that the visual system must implement a *hierarchy* of selection mechanisms operating at multiple spatial scales — top-down attention is not a single spotlight but a recursive, pyramid-coupled narrowing operation (the seed of Selective Tuning, Tsotsos et al. 1995).
10. The argument generalises beyond biological vision: any artificial vision system targeting real-time recognition under bounded compute must also implement equivalent selection mechanisms. This is the foundational complexity-theoretic argument later echoed by every successful attention model in computer vision, from the Itti–Koch saliency family to modern Transformer self-attention.

## 4. Methods

The paper is theoretical; the "method" is a complexity-theoretic reduction argument supplemented by a biological resource-budget calculation.

**Problem formalisation.** Visual Match is defined over an input alphabet of binary pixel values and a feature vocabulary of size $M$. A *configuration* is a labelling of each of $P$ pixels with a subset of features drawn from the vocabulary. The Match question is whether a target configuration is a subconfiguration of the test configuration up to a set of allowable spatial transformations (translation, scaling, in-plane rotation). Tsotsos distinguishes *Unbounded Visual Search*, in which no prior task information is available, from *Bounded Visual Search*, in which top-down information fixes some combination of expected location, expected feature subset, and expected target identity.

**NP-completeness proof.** Tsotsos reduces from a known NP-complete problem (the variant uses a SAT-style or Knapsack-style construction depending on the exact 1988 vs. 1990 statement) by encoding boolean variables as feature selections and clauses as spatial-configuration constraints. The reduction shows that any algorithm solving Unbounded Visual Search in polynomial time would solve the source NP-complete problem in polynomial time. The exponential term $2^M$ arises from enumerating feature subsets; the $2^P$ arises from enumerating pixel subsets at which the target might appear; the polynomial pre-factor $P^2$ comes from the spatial-comparison step. The proof is constructive: an explicit encoding is given, and the reduction runs in polynomial time, so the hardness is in the worst-case sense standard for NP-completeness results.

**Resource budget for biological vision.** Tsotsos estimates the time available for immediate vision at ~150–200 ms (the time before the first saccade), and the neural budget at ~$10^{10}$ neurons of which a substantial fraction are visual. Even granting the maximum biologically plausible parallelism — every visual neuron operating concurrently — the gap between this budget and the $O(2^P)$ scaling of Unbounded Visual Search for naturalistic $P$ (millions of pixel-equivalents in a single retinal image) is many orders of magnitude. The empirical fact that primates *do* recognise objects within 150 ms is therefore evidence not that brains are faster than the bound predicts, but that brains *do not solve the unbounded problem*. They solve a heavily approximated version of it.

**The four approximations.** Each is introduced as a constraint that, by itself, reduces some factor of the complexity expression:

- **Pyramidal representation:** replaces $P$ at higher levels of a multi-resolution image hierarchy with a smaller $P_\text{coarse}$, reducing the location-enumeration factor. This mirrors the empirically observed coarse-to-fine retinotopic mapping in V1 and the progressive enlargement of receptive fields up the ventral stream.
- **Localised receptive fields:** bounds the support over which a single feature detector integrates, removing combinatorial coupling across the image. A feature whose support is a small disk near pixel $i$ cannot interact with features anchored to distant pixels except through hierarchical aggregation; this collapses the $2^P$ enumeration to a sum of small local enumerations.
- **Top-down location selection:** restricts the search to $P' \ll P$ image positions chosen by task-driven attention. This is the "spotlight" or priority-map function that subsequent saliency-and-priority work (Koch & Ullman 1985; Itti & Koch 2001; Bisley & Goldberg 2010) formalised at the algorithmic level.
- **Top-down feature selection:** restricts the feature set to $M' \ll M$ task-relevant channels. This is the empirical phenomenon Treisman & Gelade (1980) called *feature-based attention* and that Reynolds & Heeger (2009) later derived as a special case of divisive normalisation under attentional gain.

**Composition.** The four approximations compose: applied together, the resulting expression $O(2^{M'} \cdot P'^{3.5})$ is tractable for $M', P'$ in the dozens-to-hundreds range that biological attentional limits permit. Tsotsos emphasises that **no single approximation is sufficient**; the brain uses all four. The pyramid handles the spatial enumeration at coarse scales, localised RFs handle the combinatorial coupling, top-down location attention handles the residual spatial cost, and top-down feature attention handles the residual featural cost. Removing any one of the four restores intractability.

**Method of inference from architecture.** Having derived the four necessary approximations, Tsotsos turns the argument around: any vision system that succeeds in real time *must* implement all four. The primate visual system therefore must implement (i) a pyramidal hierarchy (confirmed: V1 → V2 → V4 → IT), (ii) localised receptive fields (confirmed: Hubel & Wiesel), (iii) top-down location attention (confirmed: Posner cuing, parietal priority maps), and (iv) top-down feature attention (confirmed: Treisman, Moran & Desimone). The complexity argument therefore independently predicts the major architectural features of the primate visual system that anatomy and physiology reveal — a non-trivial coincidence that Tsotsos uses to argue for the explanatory force of the complexity-level analysis.

## 5. Results

The result of the paper is the complexity expression itself and its biological interpretation. There are no behavioural or neural experiments.

- **Lower bound (unbounded):** $O(P^2 \cdot 2^P \cdot 2^M)$. Intractable for biological $P, M$ by many orders of magnitude even under maximal parallelism.
- **Upper bound (bounded, attention-restricted):** $O(2^{M'} \cdot P'^{3.5})$, with $M' \ll M$ and $P' \ll P$. Tractable for biological budgets when $M'$ and $P'$ fall within the empirical attentional bottleneck ($P'$ on the order of one to a few dozen locations; $M'$ on the order of a handful of feature dimensions).
- **Implication for Marr-style theories:** any algorithmic-level proposal that does not explicitly include the four resource-reducing approximations is automatically ruled out as biologically implausible, *regardless* of how well it accounts for the behavioural data. Templates, geometric-inference, and exhaustive-matching theories of recognition are eliminated en masse. This is a strong negative result that narrows the space of viable theories considerably.
- **Implication for visual-search behaviour:** the linear search-set-size effect observed in feature search (Treisman & Gelade 1980) and the steeper-than-linear effect in conjunction search both fall out as consequences of bounded vs. partially-bounded versions of the formal problem. Pop-out for unique features corresponds to a maximally bounded ($M' = 1, P' = $ all locations in parallel) variant; conjunction search corresponds to a partially bounded variant in which features must be combined sequentially across locations.
- **Implication for cortical architecture:** the hierarchical pyramid + localised RFs + top-down feedback combination predicted by the complexity argument matches the empirical cortical hierarchy (V1 → V2 → V4 → IT) and the layer-6 corticocortical descending pathways that implement top-down selection. The complexity result therefore independently motivates the same architecture that anatomy reveals.
- **Specific tractability claim.** For typical naturalistic values ($P \sim 10^6, M \sim 10^2$), the unbounded bound is on the order of $10^{300000}$ operations; the attention-restricted bound for $P' \sim 30, M' \sim 5$ is on the order of $10^6$ operations, well within a 150 ms budget at biologically plausible per-neuron rates. The gap is the magnitude of the savings attention buys.

## 6. Critique / limitations

- **Worst-case complexity is not average-case.** The NP-completeness result concerns the worst case; natural images may have structure that makes average-case search far cheaper. Subsequent work in computer vision (efficient sliding-window detectors, learned proposal networks) shows that approximations beyond Tsotsos's four can also reshape the problem dramatically. The paper does not claim a lower bound on average-case complexity.
- **The formal problem is a model of immediate vision, not all of vision.** Recognition that admits multi-fixation strategies, language guidance, or scene gist is a different formal problem. The complexity argument applies to the within-one-fixation regime; it does not directly speak to extended search or active perception, though Tsotsos's later work extends in that direction.
- **The feature vocabulary is assumed discrete and pre-specified.** Modern learned feature representations (deep convolutional features, Vision Transformer patch embeddings) blur the line between "feature" and "image", which weakens the clean $M$ vs. $P$ separation the proof relies on. The qualitative conclusion — selection is necessary — survives this, but the specific $O(2^M)$ scaling does not transfer cleanly to learned-feature systems where $M$ is effectively continuous.
- **The four approximations are sufficient but not unique.** Other resource-reduction strategies (sparse coding, learned compression, predictive prefetching) are not in the original taxonomy and would now be added. Tsotsos's later work (and the 2017 retrospective) acknowledges this.
- **No constructive algorithm.** The paper proves that selection is necessary but does not specify how the brain *chooses* which $P'$ and $M'$ to attend to. The Selective Tuning model (Tsotsos et al. 1995) supplies a candidate mechanism (hierarchical winner-take-all with suppressive surrounds); biased competition (Desimone & Duncan 1995) and saliency (Itti & Koch 2001) supply others. The complexity argument adjudicates between these only to the extent that each must demonstrably reduce the complexity expression.
- **The complexity argument does not, by itself, motivate *recurrence***. It motivates *selection*. Whether selection is implemented in a single feedforward pass with learned weights (one ViT forward) or via iterative recurrent refinement (Recurrent ViT, Selective Tuning) is left open by the 1988 paper. Tsotsos's own program eventually argues that the suppressive-surround narrowing required by Selective Tuning is inherently recurrent — but that argument is downstream of the 1988 complexity result.
- **The 1988 statement and the 1990 *BBS* restatement differ in emphasis.** The 1988 IJCV paper foregrounds the complexity expression; the 1990 *BBS* paper foregrounds the implications for Marr's program and draws sharper conclusions about which existing theories are eliminated. Some commentaries (e.g., Uhr 1990, in the same BBS issue) pushed back on whether the unbounded formal problem is the right model of "biologically natural" search.
- **Tractability is not the same as biological realism.** Reducing complexity from $O(2^P)$ to a polynomial in $P'$ shows that the bounded problem *can* be solved by some algorithm in the available time; it does not show that the brain's specific algorithm matches Tsotsos's posited approximations. The argument is therefore necessary-condition rather than sufficient-condition: any viable theory must reduce complexity to this level, but reducing complexity to this level is not by itself a theory of vision.
- **Modern attention mechanisms challenge the discrete-feature framing.** Self-attention layers in Vision Transformers (Vaswani 2017; Dosovitskiy 2020) compute soft, learned, real-valued "attention" weights over patch tokens, with no commitment to a fixed feature vocabulary. The Tsotsos bound's $2^M$ factor presumes $M$ is a discrete enumeration; in a learned-feature setting, the analogous factor is harder to pin down, and Mehrani & Tsotsos (2023) have argued that what self-attention does in plain ViTs is *not* the Selective Tuning kind of attention the complexity argument calls for. This is an active critique the user's Recurrent ViT engages with by reintroducing recurrent iterations on top of the ViT backbone.
- **The bound assumes serial worst-case computation.** Tsotsos's NP-completeness result is the standard worst-case Turing-machine bound; massively parallel neural hardware can in principle attack the same problem with a constant-time depth circuit at the cost of exponential width. Cortex is massively parallel but not exponentially wide, so the bound still bites; nonetheless, the exact mapping between the formal bound and the brain's wall-clock budget depends on parallelism assumptions that the paper holds fixed and that subsequent work (e.g., on cortical parallelism) has refined.
- **The argument's relationship to information theory is incomplete.** A separate but related line of argument — Laughlin et al. (1998) on the metabolic cost of neural information, listed as an open scholarly debt in `the_user_architectural_program.md` §8 — derives the necessity of selection from a *metabolic* rather than a *complexity-theoretic* premise. The two arguments converge on the same conclusion (selection is necessary) but from different starting points. Tsotsos's paper does not engage the metabolic version, and a fully developed theoretical introduction to selective attention should cite both.

## 7. Connection to our work

This paper supplies the **first-principles motivation** for the user's commitment to selective attention. The line of inheritance is direct and unbroken, and the architectural choices it justifies sit at the centre of every system in the user's program.

**The complexity-necessity argument.** The Recurrent ViT does not process every pixel of every frame uniformly. It tokenises the image into patches, computes a softmax attention distribution over those patches, and the softmax — by design — concentrates representational capacity on a small subset. PRISM v1 goes further: its prediction-error map $S_t$ (`THESIS.md` §2.6) is explicitly a sparse selection mechanism that allocates downstream computation only to regions where the generative decoder is surprised. PRISM v2's dual-memory architecture (`PRISM_V2_PROPOSAL.md` §3.3) maintains a slow memory whose update is *gated* by an attention map, again selective. Each of these architectural choices is justified empirically by the change-detection benchmarks; Tsotsos's 1988 result justifies them theoretically: a system without selection cannot work within the resource budget of either biological cortex or a real-time deployed model. The user's commitment to selective attention over uniform processing is the right commitment, and this paper is the foundational argument.

**Mapping the four approximations onto the user's architecture.** Each of Tsotsos's four resource-reducing approximations has a direct analog in the user's program. (i) The *pyramidal representation* is the multi-compartmental memory stack of `the_user_architectural_program.md` §3, with Layer 1 at V1-resolution, Layer 2 at V2/V4-resolution, and Layer 3 at IT-resolution, each connected by descending and ascending conv projections. (ii) *Localised receptive fields* are the convolutional patch tokeniser at the front of the Recurrent ViT and the conv-stack descending projections between memory layers. (iii) *Top-down location attention* is the recurrent feedback into the Q/K projections that the Feedback Transformer admits at every layer (`the_user_architectural_program.md` §1) — exactly the role Selective Tuning's top-down attention signal plays. (iv) *Top-down feature attention* is implicit in the per-feedback-source Q/K projections: each feedback channel can selectively weight the feature dimensions it cares about, so a memory state focused on motion can bias the attention layer toward motion-selective features. All four Tsotsos-mandated approximations are therefore present in the user's architecture; the question is whether the *learned* implementation matches the *complexity-bound* implementation closely enough to recover the tractability the bound predicts.

**Iterate-and-narrow as Selective Tuning's structural descendant.** The user's recurrent attention pattern — multiple forward passes over the same image with attention maps that focus, defocus, and reactivate over iterations (the Food-101 classifier observation in `the_user_architectural_program.md` §6) — is structurally the same iterate-and-narrow operation Selective Tuning performs. Selective Tuning runs a feedforward sweep, then a recurrent localisation phase that uses suppressive surrounds at each hierarchical level to peel off the contribution of the attended target from the contribution of its competitors, then a second feedforward sweep over the narrowed input. The Recurrent ViT does the same thing, with the differences that (i) the suppressive surrounds are implicit in the learned softmax rather than explicit hand-engineered inhibition kernels, and (ii) the iterations are unrolled across discrete time steps with a recurrent memory $H^{(t-1)}$ rather than within a single inference. The user's Feedback Transformer primitive (`the_user_architectural_program.md` §1) generalises this further: every pass integrates feedback from multiple memory sources, each of which can carry top-down selection information into the next pass's Q/K projections.

**Connection to biased competition.** Desimone & Duncan (1995) framed attention as graded competition between neural populations under top-down bias. Tsotsos's complexity argument is the *upstream* justification for biased competition: competition is necessary because selection is necessary, and selection is necessary because unbounded vision is intractable. The user's competition-emergent predictive-coding thesis (`the_user_architectural_program.md` §5) extends this in the opposite direction: competition is not merely a readout mechanism for selection but the *origin* of the predictive architecture itself. Tsotsos motivates competition functionally (resources are scarce, so selection wins); the user motivates predictive coding from the same scarcity (coalitions must model their competitors to win). The two arguments share the resource-scarcity premise and differ in what they derive from it. The user's program can therefore be read as a deeper development of the same scarcity-driven logic Tsotsos introduces in 1988: scarcity → selection (Tsotsos) → inter-coalition competition (Desimone & Duncan) → competition-emergent predictive coding (user).

**Connection to the Itti–Koch saliency review.** `itti_koch2001_saliency_review.md` §7 establishes that the saliency-map abstraction is what the user's program *rejects*. Tsotsos's 1988 paper is the *other* side of that argument: it agrees with Itti & Koch that selection is necessary but disagrees about its mechanism — Selective Tuning's hierarchical recurrent narrowing rather than a single bottom-up topographic saliency map followed by WTA. The user's program is closer to Tsotsos than to Itti & Koch on this axis: attention is a learned, recurrent, prediction-error- or memory-conditioned selection, not a bottom-up feature-contrast computation. The complexity argument is therefore not just background motivation; it picks out a specific *family* of attention mechanisms (selective, recurrent, top-down-biased) as theoretically privileged, and the user's program sits squarely inside that family.

**Author lineage.** Mehrani & Tsotsos (2023) — `mehrani_tsotsos2023_attention_grouping.md` — is the recent argument from the same lab that what ViT-style self-attention does is *perceptual grouping*, not *attention* in the Selective Tuning sense, because it lacks the suppressive-surround narrowing step. The Recurrent ViT can be read as the architectural reply: by unrolling self-attention across multiple recurrent passes with a memory of the previous pass, it begins to recover the iterate-and-narrow operation that Mehrani & Tsotsos argue plain ViT lacks. The 1988 paper, the 1995 Selective Tuning paper, and the 2023 critique form a single author-lineage thread of complexity-theoretic argument that the user's Recurrent ViT can be cited as engaging with rather than ignoring.

**Connection to change detection specifically.** The Recurrent ViT's task is cued change detection over short video clips. In the language of Tsotsos's formal problem, this is a *bounded* visual search: the cue restricts $M'$ (the changed feature) and prior frames restrict the *expected* configuration the test image is compared against. The complexity bound therefore predicts that change detection is tractable in time linear in the test-image pixels *given the cue*, which is exactly the regime in which the Recurrent ViT operates. The change-detection failure modes the user's paper documents — missed changes in cluttered regions, false-alarm changes from camera motion — correspond to cases where the bounded-search approximation breaks down because the cue is insufficient to restrict $P'$ tightly enough. Tsotsos's bound therefore gives a principled language for *diagnosing* failures in the system, not just for justifying its existence.

**The recurrent dimension that Tsotsos's static bound omits.** The 1988 complexity argument is computed over a single feedforward sweep with top-down restriction. It does not explicitly model the *temporal* extension of attention across multiple recurrent passes that Selective Tuning later adds (and that the user's Recurrent ViT, PRISM v1's inner variational-inference loop, and the user's iterative variational encoder–decoder all rely on). However, the bound's logic extends naturally: if a single iteration cannot recover the answer because the initial $P'$ is too loose, a second iteration with a tighter $P''$ derived from the first iteration's tentative answer can. This is the iterate-and-narrow operation, and it is the recurrent counterpart of Tsotsos's static bound — each iteration further restricts $P'$ and $M'$, each iteration's complexity remains polynomial, and the whole multi-pass procedure remains tractable. The user's program operationalises this recurrent narrowing in a learned, gradient-trainable form.

**Where this paper does *not* support the user's program.** Tsotsos's complexity result motivates selection but is agnostic about *learned* vs. *hand-engineered* selection. The user's commitment to learned attention via gradient descent is a separate choice that the complexity argument does not adjudicate. Likewise, the 1988 paper has nothing to say about the user's specific architectural primitives (Feedback Transformer, GridCell RNN, multi-hub competition); it is foundational *motivation* for selective attention in general, not for any specific implementation.

**Why this paper anchors the database's "necessity of attention" thread.** The user's program engages a literature that takes attention for granted as a useful mechanism. Tsotsos's contribution is to demonstrate that attention is not merely useful; it is *required* by complexity. Any future writing that situates the Recurrent ViT or PRISM within the broader attention literature can lean on this paper as the first-principles argument that selective processing is the only viable strategy for real-time vision under bounded resources. The complexity result is also the cleanest available rebuttal to the implicit assumption in some recent large-model literature that "more compute solves vision" — the bound is exponential in pixels, so no realistic compute budget closes the gap; selection is the only path.

**Specific writing moves this paper licenses.** When introducing the Recurrent ViT or PRISM in a paper, the canonical move is: (i) cite Tsotsos 1988/1990 for the complexity-theoretic necessity of attention; (ii) cite Itti & Koch 2001 as the canonical bottom-up saliency instantiation of selection; (iii) cite Desimone & Duncan 1995 as the biased-competition readout architecture; (iv) state that the user's system implements selection via learned recurrent attention conditioned on memory and cue, rather than via hand-engineered saliency or hierarchical winner-take-all. This four-step framing situates the user's contribution within the canonical lineage and turns the architectural choice from "ad hoc engineering decision" into "a learned modern implementation of a theoretically necessary mechanism." The 1988 paper carries the load of the first step.

**Use in PRISM-specific writing.** PRISM v1's central claim is that prediction error *is* attention — the residual $S_t = \tilde X_t - \hat X_t$ doubles as both the model's surprise signal and its attentional priority map. The Tsotsos complexity argument supports this dual reading: any *selection* mechanism that collapses $P$ to $P'$ satisfies the complexity bound, regardless of how the selection is computed. PRISM's prediction-error-driven selection is therefore as theoretically licensed as Itti–Koch's saliency-driven selection or Selective Tuning's winner-take-all selection. The complexity argument is mechanism-agnostic; it picks out *that* selection must happen, not *how*.

**Use in Recurrent ViT-specific writing.** The Recurrent ViT paper (arXiv:2502.10955) frames its contribution as the addition of a recurrent memory $H^{(t-1)}$ to a ViT backbone for cued change detection. The natural complexity-theoretic reading is: the cue restricts $M'$, the recurrent memory restricts $P'$ (by carrying the pre-change frame's attention distribution), and the bounded-search regime that Tsotsos's 1988 result identifies as tractable is precisely the regime the Recurrent ViT operates in. The paper's empirical success on change detection is therefore not a coincidence but a confirmation of the theoretical prediction: bounded visual search with both kinds of top-down restriction (feature and location) is exactly the kind of problem the complexity argument says biological-style attention can solve in real time.
