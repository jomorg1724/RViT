Value-Directed Attention · Model Documentation

The architecture behind every VDA experiment

One network, one training harness, one task generator — reused unchanged across every set size, every grid, and every routing family we have run. This document describes all of it in plain language, with every number and equation needed to rebuild it from scratch.

Source of record: RViT_plus_paper_jepa_grid9/ · written 2026-08-04 · describes the code as it stands, not an idealized version of it.

Section 1What the system is

The object of study is a small artificial agent that watches a short movie and presses a button when it notices something change. It has one non-obvious property: what it remembers determines what it looks at next. Memory is not a passive record downstream of perception — it reaches back and reshapes how the next frame is read. That loop is the entire point of the model, and every experiment in this series is an attempt to measure it, break it, or steer it.

Four parts, arranged in a loop that runs once per movie frame:

  1. An eye. The frame is cut into a grid of square tiles; a small shared convolutional network turns each tile into a vector of 128 numbers. Position and time-of-frame are stapled on.
  2. A router. The tiles are mixed together by an attention operation. Crucially, the memory from the previous frame participates in this mixing — it decides which tiles get amplified and which get ignored. This is the model's attention, and it is the thing we measure and manipulate.
  3. A memory. One recurrent cell per grid location, updated each frame from the routed tiles. It is what carries "there was a stimulus here, oriented like this" across the blank frames.
  4. A decision. The whole memory is flattened into one long vector and read by two small networks: one chooses wait or declare a change, the other estimates how much reward that choice is worth.

The agent is never told where the change is. It is never told what a cue means. It is trained only by reward — press correctly, get points — plus one self-supervised auxiliary loss that asks it to predict its own future memory state. Everything the experiments report (cueing benefits, attention maps, the rescue effect) is behaviour that emerges from that training, not behaviour that was designed in.

The single most important design decision

The image is divided into exactly as many tokens as there are places worth attending to, and token i corresponds to grid cell i — a fixed, known, row-major correspondence. That makes the attention map a small, directly readable array over locations, and it makes the attention map directly writable: we can add a bias to the attention score of one specific location, mid-trial, and watch what the agent does. A conventional vision transformer with 100 anonymous patches would give us neither.

Section 2The task the agent is solving

Trial timeline

Every trial is seven logical frames of a 50×50, 75×75, or 100×100 RGB image (the size depends on the grid). Nothing about this timeline changes between experiments:

FrameWhat is on screenRole
t = 0BlackBaseline
t = 1The cue: a filled disc plus a partial ring, drawn in one grid cell, in colourTells the agent where to expect the change, how reliable that expectation is, and how much the trial is worth
t = 2BlackDelay — the cue must be held in memory from here on
t = 3, 4Gabor patches, one per active cell, each jittered by fresh orientation noise every frameStimulus array; the agent must not press yet
t = 5Same array, but on half of trials one patch steps its orientation by ΔThe event
t = 6Array continues (with the change persisting)Last chance to respond
The change time is fixed at t = 5 in every experiment reported here (--min-change-time 5 --max-change-time 5). The trainer supports a random-onset variant with a longer horizon; it is not what these runs used.

At every frame the agent picks one of two actions: wait (0) or declare a change (1). Declaring ends the trial immediately. The scoring is deliberately blunt:

  • Hit — declares at t ≥ 5 on a trial that actually contained a change. Pays the trial's reward value.
  • False alarm — declares before t = 5, or on a no-change trial. Pays zero.
  • Miss — never declares on a change trial. Pays zero.
  • Correct rejection — waits out a no-change trial to the end. Pays the trial's reward value.

Note the consequence: because responses are frame-indexed and there are only two qualifying frames (5 and 6), "reaction time" in this model has a resolution of exactly two steps. We report it at that resolution and never dress it up in continuous-time language.

What the cue actually encodes

The cue is one glyph carrying three separate pieces of information, all in a single cell of the grid:

ChannelPhysical formMeaning
LocationWhich cell the glyph is drawn inWhere the change is likely to occur
ValidityHow complete the surrounding ring is — a full ring is 100%, a quarter arc is 25%The probability p that the change will occur at the cued cell. Drawn per trial from {0.25, 0.5, 0.75, 1.0}, with 0.0 added for the larger grids
ValueThe colour of the glyph: red, green, or blueThe reward for being correct: 5, 3, or 1 points. Says nothing about where
Validity and value are crossed independently every trial, which is what makes the task "value-directed" rather than merely "cued".

Two validity conventions — and why they are never pooled

There is a subtle but consequential difference between the older and newer task variants, and the experiments treat them as separate evidence lineages:

  • Historical tasks (vda4, vda9): on the invalid branch, the change location is drawn uniformly from all N cells — which can re-select the cued cell. The realized validity is therefore p + (1−p)/N, not p.
  • Controlled tasks (vda_fixed*): the invalid branch samples only from the N−1 non-cued cells, so displayed and realized validity are exactly equal.

Both live in the codebase (_draw_change_index versus _draw_validity_target). Mixing results across the two would silently confound the very quantity under study.

The curriculum

Detection difficulty is not fixed — it is earned down. The maximum orientation change θ starts at 65°, and each trial's actual change is drawn Δ ~ U(−θ, +θ). Every 1,000 trials the environment checks the agent's accuracy over that window; if it is at or above 85%, θ drops by 3°. The floor is 8°. Nothing ever raises θ back up.

Why the final θ matters when reading results

θ at the end of training is a competence measure, not a hyperparameter. A checkpoint that finished at θ = 65° never once cleared the 85% gate — it is still on the easiest setting the curriculum offers. A checkpoint at θ = 47° cleared it six times. Several results in the manuscript are explicitly labelled competence-gated for exactly this reason, and comparisons across checkpoints with different terminal θ are not like-for-like.

The discretization dimension

One further axis, and it is the one most easily misread. The stimulus grid (how many Gabors are on screen) and the token grid (how finely the image is cut up for the model) are set independently, via --patch-grid-rows/--patch-grid-cols. A vda4 trial — four Gabors, unchanged pixels — can be handed to a model that sees it as 4 tokens, 16 tokens, or 100 tokens. Below 1:1, several tokens tile a single stimulus and the one-token-per-item correspondence is deliberately broken. That is the experiment: does finer spatial competition make attention matter more, even when the number of things to remember is fixed?

Section 3The model, end to end

In code this is one call, model.rl_step(frame, state), which returns the action logits, the value distribution, the attention map, and the new state. The same computation batched over a whole trial is forward_rl_sequence. The recurrent state is carried as an opaque tuple — the training harness never inspects it.

Section 4Seeing — the patch encoder

The frame arrives as a 3-channel RGB image. Colour is not decorative: the cue's value is carried entirely by hue, so a grayscale front-end would destroy the manipulation.

The image is cut row-major into R × C equal tiles. Each tile goes through the same small convolutional network — one set of weights, applied everywhere, so nothing about a location is learned in the encoder itself. The network is a compact SE-ResNet:

stem Conv 3×3 (3 → 32), GroupNorm, SiLU stage 1 SE-residual block, 32 → 64, stride 2 25px → 13px stage 2 SE-residual block, 64 → 128, stride 1 13px → 7px stage 3 SE-residual block, 128 → 128, stride 1 depth, no downsample pool global average → 128 numbers norm RMSNorm (scale only, mean preserved)

Each SE-residual block is: Conv3×3 → GroupNorm → SiLU → Conv3×3 → GroupNorm → squeeze-excite → add the input back → SiLU. The squeeze-excite step pools each channel to a single number, passes it through a tiny bottleneck, and uses the result to rescale that channel — cheap channel-level attention inside the encoder.

Each tile's 128-number embedding is then concatenated with two one-hot vectors:

token_i = [ embedding (128) ‖ which cell (N) ‖ which frame (8) ] token width d = 128 + N + 8 140 at N=4 · 152 at N=16 · 236 at N=100 X = (B, N, d)

The frame index is clamped into 8 slots, which comfortably covers the 7-frame trial. Position is a plain one-hot rather than a learned embedding, so the spatial index stays literally readable — necessary for the intervention machinery downstream.

Two deliberate deviations from standard practice

GroupNorm, not BatchNorm. During online rollout the model runs with a batch of one, frame by frame. BatchNorm's running statistics are fragile in that regime and make training and evaluation behave differently. GroupNorm is batch-independent and identical in both modes.

RMSNorm, not LayerNorm, on the pooled embedding. LayerNorm subtracts the mean, which would attenuate a uniform colour offset — exactly the signal the value cue uses. RMSNorm rescales without recentring, so the DC component survives.

The front-end is trained end to end from reward. There is no pretraining, no reconstruction loss, no frozen encoder. (An earlier VAE-based front-end fixed to a 2×2 / 50 px layout still exists in the repository and is refused for any other geometry, but no VDA experiment reported here uses it.)

Section 5Routing — where memory meets vision

This is the mechanism the whole project is about. The tokens X from the current frame and the memory H from the previous frame are combined into Z, the representation that will be written to memory. How memory participates in that combination defines a routing family, and the family is a first-class experimental variable — several results hold for one family and not the other, which is itself a finding.

Two families carry the VDA experiments.

Cross-attention — crossattn1

The current image asks the questions; both the image and memory offer answers.

Q = W_q(X) N queries, from vision only K = [ W_kx(X) ‖ W_kh(H) ] 2N keys: N visual, then N memory V = [ W_vx(X) ‖ W_vh(H) ] 2N values, same layout A = softmax( Q Kᵀ / √d ) (B, N, 2N) Z = X + A · V residual on X

The attention map is N × 2N. Key j for j < N is "the image at location j"; key N + j is "what I remember about location j". Because the two streams are separate columns of one softmax, the map states not just where the model is attending but whether it is currently looking or currently remembering — a distinction the analysis code uses directly (it reports visual-source and memory-source mass before they are summed).

Affine modulation — affine_ew

Memory does not compete for attention. Instead it rewrites the visual features first, and then a plain self-attention runs over the rewritten features.

b = tanh( bottleneck(H) ) H → 64 dims γ = scale(b) ∈ ℝ^d element-wise gain, init 1 β = shift(b) ∈ ℝ^d element-wise offset, init 0 X' = γ ⊙ X + β no "1 +" identity term Q,K,V = W_XQ(X'), W_XK(X'), W_XV(X') A = softmax( Q Kᵀ / √d ) (B, N, N) Z = X + A · V residual on the UNmodulated X

Only N keys here — half as many spatial keys as cross-attention for the same token count. Note the initialization: γ starts at 1 and β at 0, so the block begins life as ordinary self-attention over the raw image and the memory's influence grows as training proceeds. Zero-initializing the gain instead would collapse X' to zero and kill attention before it started; this is a real failure mode the code comments call out by name.

Why the comparison is fair

Both routers see the same tokens, write to the same memory, use the same readout, and are trained by the same harness with the same hyperparameters. They differ in one thing: whether memory competes for attention as an explicit set of keys, or silently reshapes the features that attention then operates on. When a result appears under one and not the other, that is the difference doing the work.

Section 6Remembering — the spatial xLSTM

The routed tokens Z are written into memory by an xLSTM cell: an LSTM whose input and forget gates are exponential rather than sigmoidal, with a running normalizer that keeps the result bounded. It updates each of the N locations independently, using one shared set of weights — so the memory has spatial structure without the cell knowing anything about geometry.

Ĩ = Z·W_i + H·R_i F̃ = Z·W_f + H·R_f Õ = Z·W_o + H·R_o Ũ = Z·W_u + H·R_z M = max( F̃ + M_prev , Ĩ ) stabilizer — keeps exp() finite I = exp( Ĩ − M ) input gate F = exp( F̃ + M_prev − M ) forget gate O = σ(Õ) U = tanh(Ũ) N_t = F ⊙ N_prev + I normalizer C_t = λ · (C_prev ⊙ F) + U ⊙ I cell content H_t = O ⊙ ( C_t / N_t ) the readable memory

Four states are carried per location: H (output), C (content), N (normalizer), M (log-space stabilizer). All start at zero, which makes the first frame's output well defined as O ⊙ U. Input weights carry a bias; recurrent weights do not.

Two experimental knobs live inside this cell

  • --memory-decay λ (default 1.0 = off). λ multiplies only the content carried over from the previous frame; what is written this frame is untouched. It implements a clean forgetting rate that is independent of what the gates decide to do. Setting λ = 1 recovers the original xLSTM equation exactly.
  • --memory-noise-std (default 0 = off). Gaussian noise added to the cell content, scaled by the same normalizer that divides C — so the noise level is expressed in the units the readout actually sees and cannot blow up when the normalizer is near zero. The perturbed content is carried forward, so the corruption compounds across frames, as a memory noise model should.

Two alternative cells exist for ablations: layernorm_lstm (carries only H and C, normalizes the content) and softmax_head (a categorical state that is both the memory and the readout). Every VDA result reported uses xlstm.

Section 7Deciding — actor and critic

The spatial structure is deliberately dropped at the decision stage. The memory (B, N, d_mem) is flattened to a single vector of length N · d_mem, and two independent networks read it. Neither has any notion of location; if the agent's decisions are spatially sensitive, that sensitivity had to be built upstream.

Both heads are the same trunk — three fully connected layers of 256 units with ELU activations — and differ only in what they emit:

  • Actor → 2 logits, softmaxed into P(wait) and P(declare). The output bias is initialized to [0.0, −1.5], which makes the untrained agent strongly prefer waiting. Without this the agent presses constantly at the start, every trial ends at frame 0, and it never sees a stimulus to learn from.
  • Critic → 2 actions × 5 quantiles. Rather than a single expected value, it predicts five points of the return distribution, at quantile levels 0.1, 0.3, 0.5, 0.7, 0.9. The state value is the policy-weighted mixture: V_dist = Σ_a π(a) · Q_dist(a), and its mean is the scalar value.

Section 8The prediction loss

Reward alone is a thin training signal in this task: one scalar, once per trial, on a problem that requires holding a cue across a blank frame. A self-supervised auxiliary loss supplies dense, per-frame gradient by asking the model to predict its own future memory state.

The scheme is DINO-style self-distillation applied along time (a V-JEPA arrangement):

  1. A teacher copy of the network is maintained as an exponential moving average of the student, with its own decay (0.996) kept separate from the reinforcement-learning target network.
  2. Both run the same trial. A small head maps each location's memory state to 4 groups of 256 logits, each group softmaxed independently — so each location emits four separate categorical codes rather than one flat distribution.
  3. The teacher's distribution at frame t+1 is centred (by a running mean) and sharpened (temperature 0.04 → 0.07 over 300 iterations). The student's distribution at frame t is softened (temperature 0.1). The loss is the cross-entropy between them.
  4. The running centre is updated as an EMA (momentum 0.9) — the standard guard against the collapse where every state maps to the same code.

Weight: --jepa-coef 0.5 in every VDA run. A same-time ablation (predict the present rather than the future) is available via --jepa-same-time.

Section 9How it is trained

Reinforcement learning, but not PPO despite the file name. The actor is updated by a PAC/MPO rule and the critic by quantile regression, both against a time-lagged target copy of the network, with prioritized replay of whole episodes.

One iteration

  1. Collect. Run 8 complete trials, one at a time, carrying the recurrent state within each. Actions are sampled from the policy, not taken greedily.
  2. Replay. Draw 4 past episodes from a 1,000-episode prioritized buffer and append them to the batch. Priority is the episode's mean critic loss; sampling exponent α = 0.6; the importance weight exponent β anneals 0.4 → 1.0 across the run.
  3. Update. Four gradient passes over the combined batch of 12 episodes.
  4. Track. Update the target network, the JEPA teacher, and the replay priorities.

The losses

L = L_actor + 0.5 · L_critic − 0.01 · entropy + 0.5 · L_jepa

Critic. A one-step distributional TD target, r_t + γ · V_dist(s_{t+1}) · (1 − done), bootstrapped from the target network so the goalposts do not move within an update. The loss is quantile Huber (κ = 1.0) over all 25 quantile pairs.

Actor. The MPO expectation step has a closed form over two discrete actions:

q(a|s) ∝ exp[ log π_target(a|s) + Q̄(s,a) / η ] η = 0.1 L_actor = (1 − α) · ( −Σ_a q(a|s) log π(a|s) ) fit the improved policy + α · ( −log π(a_t|s) ) α = 0.1, behaviour cloning

The reference policy is the lagged target, not the current policy — that is the stabilizer. The behaviour-cloning term anchors the update to actions actually taken.

Stabilizers that matter in practice

  • Burn-in. For the first 20 iterations the agent is forced to wait every frame. Every trial runs to full length, and only the critic and representation train. This warms up the value function on complete trajectories before the policy is allowed to truncate them.
  • Two-stage gradient clipping. A per-element clip first (guarding against a single huge gradient producing an infinite norm), then a global L2 clip at 0.5. If the norm is still non-finite the step is dropped and counted, never silently applied.
  • EMA target. θ′ ← 0.995·θ′ + 0.005·θ every iteration, replacing periodic hard copies.
  • Masked padding. Trials that end early are padded to 7 frames by repeating the last real frame — not with black — so the recurrent encoder settles rather than drifting. A validity mask zeroes those steps in every loss.

Section 11The causal lever

Everything above is observational. The reason the architecture is shaped the way it is — one token per location, a fixed row-major index, a raw one-hot position code — is so that attention can be intervened on rather than merely watched.

The hook is deliberately minimal. Inside every routing module, immediately before the softmax, one line adds a constant to the attention score of a chosen key:

scores[..., j] += b then softmax as usual

Nothing else changes: no weights are edited, no trial is altered, no gradients are involved. The bias is parameterized by a dose α ∈ [0, 1]:

b = 6.0 · (2α − 1) α = 0.0 → b = −6 suppress this location α = 0.5 → b = 0 no manipulation (the natural condition) α = 1.0 → b = +6 boost this location

Under cross-attention, a "location" is two keys — the visual key j and the memory key N + j — and both receive the bias, so the manipulation targets the place rather than the stream. Under affine routing there is one key per location. The clamp is switched on at frame 5 (the change frame) and held through the end of the trial.

The rescue experiment, as an illustration

The design that this hook makes possible: take invalid trials — where the cue pointed one way and the change happened somewhere else, the condition the agent is worst at — and apply the bias at three different places, holding everything else fixed.

Target of the biasRolePrediction if attention is causal
The true change locationThe testSuppressing it should destroy detection; boosting it should restore it
The cued (wrong) locationNegative controlShould not rescue — the change is not there
A third, irrelevant locationSpecificity controlShould not rescue — it is spatially unrelated
300 trials per condition; a response counts only at frame 5 or 6; sensitivity and criterion are decomposed separately so a change in hit rate is never mistaken for a change in evidence.

The measured result on the VDA16 cross-attention checkpoint: detection on invalid trials falls from 51% to 7% under suppression and rises to 95% under boost, closing 92% of the gap to the valid-cue ceiling — while neither control location reproduces it. That double dissociation, spatially specific in both directions, is the headline causal result of the manuscript.

Discipline around this tool

The intervention script introduces no model code. It composes primitives that already existed and were already tested: the graded key bias, forced-location trial generation, and the signal-detection reduction. It also refuses to run against a checkpoint whose SHA-256 does not match its registered value — a missing or altered checkpoint is recorded in the manifest as blocked, never quietly skipped. Two arms of the original design (VDA9, and parts of the fixed-grid family) are recorded as blocked for exactly this reason.

Section 12Reproducing a run

Training a checkpoint is a single command. The canonical VDA16 cross-attention run:

python train_rl.py \ --task vda16 --T 7 --min-change-time 5 --max-change-time 5 \ --cell xlstm --feedback crossattn1 --memory-decay 1.0 \ --conv-frontend --patch-grid-rows 4 --patch-grid-cols 4 \ --jepa-coef 0.5 --d-mem 128 --curriculum \ --init-mode fresh --iters 20000 --schedule-final-iteration 19999 \ --episodes-per-iter 8 --save-every 50 --log-every 1 \ --seed 0 --device cuda --checkpoint-dir <OUT>

Its affine counterpart is the same line with --feedback affine_ew. The discretization experiment keeps --task vda4 — identical pixels — and changes only --patch-grid-rows/-cols to 2, 4, or 10.

What a run writes

  • launch_manifest.json — the full argument vector, interpreter path, launcher script, and a timestamped run identifier, written before training starts.
  • metrics.csv — one row per iteration, flushed immediately: every loss term, gradient norm, skipped-step count, replay buffer state, rolling accuracy, and current curriculum θ.
  • rvit_plus_rl_latest.pt / ..._final.pt — model, optimizer, target network, JEPA teacher, RNG state for every backend, and the environment's curriculum state.
  • train.log — the console transcript.

Resumption is contract-checked, not best-effort. load_training_state_dict refuses a checkpoint whose environment configuration differs from the live environment in any field, whose curriculum settings differ, or whose θ falls outside the configured bounds. The metrics schema must match before a resumed run is allowed to append. A run that cannot be resumed exactly fails loudly instead of continuing on slightly different terms.

What counts as a completed checkpoint

For a run to be admitted as evidence: the trainer must have exited cleanly; metrics.csv must contain exactly contiguous finite rows for iterations 0 through 19,999; final and latest checkpoints must exist and be semantically equal; schema, config, and provenance validation must pass; and local and remote SHA-256 values must match. Only then does the checkpoint run the held-out evaluator — 300 psychometric trials, 128 attention trials, and 250 intervention trials per condition, on trials the training run never saw.

One sentence, if you only keep one

A shared tile encoder turns each frame into one token per place; the previous frame's memory decides how those tokens are routed; an xLSTM keeps one memory per place; a flat readout decides whether to press — and because the routing is indexed by place, we can reach in mid-trial, bias attention at any location we choose, and measure what breaks.
